Live dashboard setup

A Google Sheet that shows one row per student, updated live. Do this once; reuse the URL for every exam.

  1. Create a new Google Sheet.
  2. Open Extensions → Apps Script, delete the sample code and paste in apps-script/Code.gs from the LockIn folder.
  3. Optional: put a secret between the quotes in const SHARED_SECRET = ""; and type the same secret above.
  4. Choose the setup function and press Run once. Allow the permissions it asks for.
  5. Deploy → New deployment → Web app. Execute as Me, who has access Anyone. Deploy.
  6. Copy the URL ending in /exec into Webhook URL above.
  7. In the Sheet, set File → Settings → Calculation → Recalculation to "On change and every minute" so the Online column stays current.

Full instructions are in README.md in the LockIn folder, or on GitHub.
